ICMS

Tributo considerado pelo sistema conforme a alíquota cadastrada para o produto.

IPI

Tributo incluído no cálculo quando existir alíquota correspondente cadastrada.

PIS e COFINS

Considerados separadamente na composição da estimativa tributária.

Funrural

Percentual cadastrado para a simulação da operação.

SENAR

Considerado de acordo com o cadastro utilizado pelo sistema.

Sobre o projeto

AgroTax

O AgroTax é uma plataforma web criada para auxiliar produtores rurais, cooperativas, contadores e profissionais do agronegócio brasileiro na estimativa da carga tributária de operações envolvendo produtos agrícolas.

O projeto reúne uma calculadora tributária, um guia fiscal e uma API responsável pelo processamento das simulações.
